# Tiri

**为编程智能体打造的 Mac 工作区。说一句就能改，连源代码也不例外。**

![智能体不用换，配套一应俱全。一个真实的 Tiri 窗口：四个工作区，其中一个里 Grok 正在等你回应；Claude Code 在 Tiri 自己的源代码里，用速览打开了功能介绍页：一项任务一个工作区、不只是代码、速览、智能体也能操作 Tiri、还能自我改进。角落里是“修改 Tiri”输入框。](.github/readme/tiri.png)

## 为什么不用别的工具？

| 如果选 | 比如 | 就得放弃 |
|---|---|---|
| AI 编辑器 | Cursor、Windsurf、Zed | **你自己的智能体**。它自家的优先，你的只能挤在编辑器底下的抽屉里。 |
| 官方应用 | Claude Code 桌面版、Codex 应用 | **其他所有智能体**，还有你自己配好的 CLI。 |
| 智能体管理器 | Conductor、Superset、Emdash | **你用惯了的仓库**。每件事都成了一项任务，开在全新的工作树里。 |
| 终端 | cmux、Warp、Ghostty + tmux | **智能体之外的一切**。终端是主角，别的都靠边站；输出里的路径要是写错了，点了也白点；智能体在哪儿启动，全看 shell 当时碰巧在哪个目录。 |

**用 Tiri，一样都不用放弃。**

## 想改哪里，说一声就行

每个人的习惯都不一样，所以 Tiri 随你改。不是调一项设置，也不是走插件 API：改的是真正的源代码。

1. 选择 **修改 Tiri…**，指着任意一处，说出你想要的样子。
2. 你自己的智能体去改 Tiri 的源代码，用的也是你自己的订阅。
3. 点 **试用**。Tiri 大约半秒就重新打开，你的智能体照常运行。
4. 保留这项更改，或者点一下回到原样。

- **什么都能改**：布局、行为、快捷键、某个按钮的作用，或者 Tiri 还没有的功能。
- **长期有效**：每次更新都会保留你的更改。哪天 Tiri 自带了同样的功能，你的更改会自动让位。
- **安全**：智能体可以把更改做出来，但只有你能切换过去。想回原版 Tiri，随时点一下就行。

## 智能体输出的每条路径，都能原地打开

- **按住 ⌘ 点按智能体输出里的路径**，文件就浮在会话上方，布局纹丝不动。这就是速览。
- **路径写错了也打得开**。Tiri 会找到智能体本来想指的那个文件，或者让你来选。
- **智能体自己也能打开**。`tiri open report.md` 会把它做好的东西浮到你眼前，键盘焦点仍留在会话里。
- **对任何一处更改点“撤销”或“询问”**，请求都会交给当初动手的那个智能体：文字已经填进它的输入框，只等你按 Return。

## 原有的，一样不少

- **你的智能体，原封不动**。跑的就是原本的 CLI，配置、钩子和订阅都是你自己的。
- **哪个智能体都行**。Claude Code、Codex、Grok，或者你自己添加的任何命令。
- **你的肌肉记忆**。快捷键、文件浏览器和工作区，用起来和 Cursor、VS Code 一样。
- **你的 Git 工作流**。智能体就在你的仓库里干活，它们开的分支 Tiri 都找得到。
- **你的服务器**。直接用你自己的 SSH 配置连接，只需一个 90 KB 的辅助程序，不用 root。
- **这套环境，永远是你的**。不用注册账户，背后也没有我们的云服务，采用 MPL-2.0 许可证。

## 还多了这些

- **所有智能体一目了然**：各自在忙什么，哪个在等你。
- **写给智能体，有个像样的输入框**。按 ⌘↩，它就在终端底部打开，打字、贴图、放文件、粘贴大段内容都行。写到一半智能体要是来问你，你的消息会先等着。
- **文件、差异和网页都是标签页**，和终端平起平坐。这里没有终端抽屉。
- **应用关了，智能体照跑**。退出、崩溃、和服务器断开连接，它们都不会停。
- **开发服务器集中管理**。点一下“▶ 启动”，每个工作区的服务器和启动脚本就都跑起来，所有智能体共用同一套，不会各起一份。
- **先选文件夹**：你没说在哪儿，就什么都不会启动，所以智能体不会跑错地方。
- **按轮查看差异**：看清每条提示词改了什么。
- **什么都能批注**：指着图片或 PDF 上的某一处、网页里的某个元素，或者点按某一行旁边的 +，说哪里不对。批注可以跨文件攒着，再跟着你的消息一起发给智能体。
- **⌘L** 把选中的内容引用给智能体；在 Claude Code 里，用的就是它原生的 @ 引用。

## Tiri 的理念

- **智能体负责写，你负责读和判断**。一切以阅读为先，所以没有 AI 的灰字补全。
- **不自带 AI**。Tiri 不卖东西，不搞推销，也从不烦你。
- **Git 不用人来操作，交给智能体**。获取、拉取和推送点一下就行；其余的，跟智能体说一声。
- **你不点头，什么都不会发给智能体**。批注、“撤销”和“询问”都等你亲自发送。
- **绝不打断你**。提醒不会打乱标签页的顺序，在速览里按 Esc 也传不到智能体那儿。
- **你能做的，智能体都能做**，靠的是 `tiri` 命令。
- **改设置有两条路：设置界面，或者你的智能体**。你永远不用手改 JSON 文件。
- **不重复造智能体**。技能、钩子和 MCP 都留在你的智能体里，插件只补终端画不出来的东西。
- **原生，而且快**。用 Swift 写成，不用 Electron，也绝不为了速度砍功能。

## 什么时候该用别的工具

- **需要云端沙盒或任务看板**，请用智能体管理器。
- **整天都在亲手写代码**，请用编辑器。Tiri 是为阅读和审阅而生的。
- **用的是 Windows、Linux 或 Intel Mac**。Tiri 需要搭载 Apple 芯片的 Mac 和 macOS 26。

## 安装

[下载 Tiri](https://tiri.build/download/Tiri.dmg)，或者用 Homebrew：

```sh
brew tap tiri-build/tap
brew install --cask tiri-build/tap/tiri
```

Tiri 需要搭载 Apple 芯片的 Mac 和 macOS 26。选一个智能体，再选一个文件夹。Tiri 问要不要安装钩子时，点“安装”。

想自己构建的话，先装好命令行工具（`xcode-select --install`）或 Xcode 26：

```sh
./build.sh && open build/Tiri.app
```
