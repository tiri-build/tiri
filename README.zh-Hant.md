# Tiri

**專為程式開發代理打造的 Mac 工作區。想改什麼說一聲，連原始碼都能改。**

![代理不用換，周邊全到位。一個真實的 Tiri 視窗：四個工作區，其中一個有 Grok 在等你回應；Claude Code 正在 Tiri 自己的原始碼裡，用速覽打開了功能介紹頁：一項任務一個工作區、不只是程式碼、速覽、代理也能操作 Tiri、Tiri 會自我改進。角落是「修改 Tiri」輸入框。](.github/readme/tiri.png)

## 為什麼不用別的？

| 如果你選 | 例如 | 你放棄的是 |
|---|---|---|
| AI 編輯器 | Cursor、Windsurf、Zed | **你的代理**。它自家的代理優先，你的只能窩在編輯器底下的抽屜裡。 |
| 原廠 App | Claude Code 桌面版、Codex App | **其他所有代理**，還有你設定好的 CLI。 |
| 代理管理工具 | Conductor、Superset、Emdash | **你用慣的儲存庫**。每件事都得變成一項任務，開在全新的工作樹裡。 |
| 終端機 | cmux、Warp、Ghostty + tmux | **代理周邊的一切**。終端機優先，其他的都只能擺在一旁；輸出裡的路徑要是寫錯，就什麼也打不開；代理在哪裡啟動，全看你的 shell 剛好停在哪裡。 |

**用 Tiri，一樣都不用放棄。**

## 想改哪裡，說一聲就行

每個人的工作習慣都不同，所以 Tiri 由你來改。不是調某個設定，也不是透過外掛 API：你改的是真正的原始碼。

1. 選「修改 Tiri…」，指著任何一個地方，說出你想要的樣子。
2. 由你自己的代理修改 Tiri 的原始碼，用的是你自己的訂閱。
3. 按「試用」。Tiri 大約半秒就會重新打開，你的代理照常執行。
4. 保留這項變更，或按一下就回到原樣。

- **什麼都能改**：版面配置、行為、快速鍵、某個按鈕的作用，或是 Tiri 還沒有的功能。
- **不會消失**：每次更新都會保留你的變更。如果 Tiri 之後內建了同樣的功能，你的變更會自動讓位。
- **安全**：代理可以把變更做出來，但只有你能切換過去。想回到原版 Tiri，隨時按一下就行。

## 代理輸出的每個路徑，都能原地打開

- **在代理的輸出裡按住 ⌘ 按一下路徑**，檔案就會浮在工作階段上方，不會動到你的版面配置。這就是速覽。
- **寫錯的路徑也打得開**。Tiri 會找出代理指的是哪一個，或讓你自己選。
- **代理也能自己打開東西**。`tiri open report.md` 會讓它做好的東西浮在上方給你看，鍵盤焦點仍留在工作階段裡。
- **在任何一處變更上按「還原」或「詢問」**，都會交給當初動手的代理：內容已經填進它的輸入框，就等你按 Return。

## 原本的，都還在

- **你的代理，原封不動**。它就是原本那個 CLI，用的是你的設定、掛鉤和訂閱。
- **哪個代理都行**。Claude Code、Codex、Grok，或任何你自己加入的指令。
- **你的肌肉記憶**。快速鍵、檔案總管和工作區，用起來和 Cursor、VS Code 一樣。
- **你的 Git 工作流程**。代理直接在你的儲存庫裡工作，它們開的分支，Tiri 都找得到。
- **你的伺服器**。用你自己的 SSH 設定連線，只要一個 90 KB 的輔助程式，不需要 root。
- **你的環境，永遠是你的**。不需要帳號，沒有什麼「Tiri 雲端」，採用 MPL-2.0 授權。

## 另外，還多了這些

- **所有代理一目了然**：誰在做什麼、誰在等你。
- **寫給代理，有個像樣的輸入框**。按 ⌘↩，它就在終端機底部打開，能打字、放圖片和檔案、貼上大段文字。代理中途要是問了什麼，你的訊息會先等著。
- **檔案、差異和網頁都是分頁**，和終端機平起平坐，沒有所謂的終端機抽屜。
- **App 關了，代理還在**。不管是結束 App、App 閃退，還是和伺服器斷線，它們都不會停。
- **開發伺服器集中一處**。「▶ 啟動」會執行每個工作區的伺服器和啟動指令碼，所有代理共用同一組，不會各開各的。
- **先選資料夾**：你還沒指定位置之前，什麼都不會啟動，所以代理不會跑錯地方。
- **每一輪的差異**：每下一次提示詞，改了哪些地方都看得到。
- **什麼都能加註記**：指著圖片或 PDF 上的某一處、網頁裡的某個元素，或按一下某一行旁邊的 +，說哪裡不對。註記可以跨檔案累積，再跟著你的訊息一起送給代理。
- **⌘L** 把選取的內容引用給代理；在 Claude Code 裡會變成真正的 @ 提及。

## Tiri 的理念

- **代理負責寫，你負責讀和判斷**。一切以好讀為優先，所以沒有 AI 那種灰色的建議文字。
- **沒有自己的 AI**。Tiri 什麼都不賣、什麼都不推銷，也絕不煩你。
- **操作 Git 的不是人，是代理**。擷取、拉取和推送按一下就好，其餘的都開口請代理做。
- **沒有你點頭，什麼都不會送給代理**。註記、還原和詢問，都會等你親自送出。
- **絕不打斷你**。通知不會打亂你的分頁順序，在速覽裡按 Esc 也不會傳到代理那邊。
- **你能做的，代理都能做**，靠的是 `tiri` 指令。
- **設定有兩個入口：設定畫面和你的代理**。你永遠不必手動改 JSON 檔。
- **不另外再做一個代理**。技能、掛鉤和 MCP 都留在你的代理那邊，外掛只補上終端機畫不出來的東西。
- **原生，而且快**。以 Swift 打造，不用 Electron，也絕不為了速度砍功能。

## 什麼時候該用別的

- **如果你需要雲端沙盒或任務看板**，請用代理管理工具。
- **如果你整天都在自己寫程式**，請用編輯器。Tiri 是為了閱讀和審閱而設計的。
- **如果你用的是 Windows、Linux 或 Intel Mac**，也請用別的：Tiri 需要 macOS 26 和 Apple 晶片。

## 安裝

[下載 Tiri](https://tiri.build/download/Tiri.dmg)，或用 Homebrew 安裝：

```sh
brew tap tiri-build/tap
brew install --cask tiri-build/tap/tiri
```

Tiri 需要 macOS 26 和 Apple 晶片。選一個代理，再選一個資料夾。Tiri 問你要不要安裝掛鉤時，按「安裝」。

想自己建置的話，需要命令列工具（`xcode-select --install`）或 Xcode 26：

```sh
./build.sh && open build/Tiri.app
```
